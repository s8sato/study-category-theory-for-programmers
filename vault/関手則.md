# 関手則（Functor Laws）

[[関手]] `F` が「構造を保つ」と言えるためには、次の2つの法則を満たす必要があります。

1. 恒等射の保存: $F(\mathrm{id}_a) = \mathrm{id}_{Fa}$
2. 合成の保存: $F(g \circ f) = F g \circ F f$

Haskellの `Functor` 型クラスで書けば、次のようになります。

```haskell
fmap id      == id
fmap (g . f) == fmap g . fmap f
```

これらはコンパイラが自動でチェックしてくれる法則ではなく、`Functor` インスタンスを書く開発者自身が守るべき「契約」です。もしこの法則が破られると、`fmap` を使ったコードが直感に反する挙動を示す可能性があります。たとえば「リストの各要素を2倍してから3を足す」処理と「先に3を足してから2倍する」処理を、正しく `fmap` の合成則に沿って書き換えられなくなってしまいます。関手則は、抽象化を安全に積み重ねるための最小限の約束事です。
