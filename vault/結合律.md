# 結合律（Associativity Law）

結合律は、[[合成]] が満たすべき法則で、次のように表されます。3つの射 `f :: a -> b`、`g :: b -> c`、`h :: c -> d` があるとき、

$$h \circ (g \circ f) = (h \circ g) \circ f$$

が常に成り立つ、というものです。つまり、複数の射をまとめて合成するとき、どの順番で2つずつペアにして計算しても、最終的な結果は変わりません。

これはHaskellの関数合成 `(.)` でも当然成り立つ性質で、`h . (g . f)` と `(h . g) . f` は同じ関数を表します。実務のプログラミングでは意識することが少ない性質ですが、パイプライン処理やミドルウェアの合成など、「処理を繋げる」あらゆる場面の裏側にはこの結合律が暗黙に使われています。

結合律と、[[恒等射]] が合成の単位元であること、この2つだけが [[圏]] の定義に必要な法則のすべてです。
