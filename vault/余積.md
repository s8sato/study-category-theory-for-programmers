# 余積（Coproduct）

余積は [[積]] の双対概念です。2つの対象 `a`、`b` の余積とは、対象 `c` と、2本の射（注入）$i: a \to c$、$j: b \to c$ の組であって、同じ形の候補 `c'` へ、`c` から一意な射 `m` が常に存在する（[[普遍性]]）、最も条件の厳しい候補のことです。

![[coproduct.png|対象a,bから候補c,c'への注入i,jと、c同士を繋ぐ一意な射m]]

[[Set圏]] では、余積は非交和（disjoint union）に対応します。[[Hask圏]] では `Either a b` 型がこれにあたり、注入は `Left :: a -> Either a b`、`Right :: b -> Either a b` というコンストラクタです。

積が「両方の情報を保持するペア」であるのに対し、余積は「どちらか一方の情報を保持するタグ付き union」です。直感的には、積は AND、余積は OR に近い関係にあり、[[直積型と直和型]] としてプログラミング言語の型システムにそのまま現れます。
