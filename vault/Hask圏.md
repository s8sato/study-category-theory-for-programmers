# Hask圏（Category of Haskell Types and Functions）

Hask圏は、対象を Haskell の型（`Int`、`Bool`、`[a]` など）、射を型と型の間の関数（`f :: a -> b`）とする [[圏]] です。プログラマにとって最も具体的で理解しやすい圏の例と言えるでしょう。

- 恒等射は `id :: a -> a`
- [[合成]] は関数合成 `(.) :: (b -> c) -> (a -> b) -> (a -> c)`

という対応になります。Haskellの `(.)` 演算子が結合律を満たすこと（`h . (g . f) == (h . g) . f`）は、実際に型検査器やコンパイラのレベルで保証されているわけではありませんが、純粋関数である限り数学的に成り立ちます。

同様のことは他の言語でも成り立ちます。TypeScriptの関数合成や、Javaのメソッドチェーンも、副作用を無視すれば同じ構造を持っています。Hask圏は [[Set圏]] とよく似ていますが、「型」という、値の集合よりも構文的に扱いやすい単位を対象にしている点が実務上のメリットです。
