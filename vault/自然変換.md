# 自然変換（Natural Transformation）

自然変換は、[[関手]] と関手の間の「変換」です。2つの関手 `F`、`G` が同じ圏 `C` から圏 `D` への関手であるとき、自然変換 `α` は、`C` の各対象 `a` ごとに、`D` における射 $\alpha_a: F a \to G a$ を1つずつ割り当てる操作です。

ただし、どんな割り当て方でもよいわけではありません。次の「自然性」という条件（[[自然性条件]]）を満たす必要があります。

![[naturality-square.png|射fに対してFf,Gfとα_a,α_bが作る可換な正方形]]

Haskellでは、自然変換は「多相関数（polymorphic function）」として現れます。たとえば `safeHead :: [a] -> Maybe a` は、リスト関手からMaybe関手への自然変換です。型変数 `a` に何を入れても定義が一様に決まる（`forall a.`）関数は、ほぼすべて自然変換とみなせます。

自然変換は「関手同士がどれだけ関連しているか」を測る道具であり、圏論のより高度な話題（極限や随伴など）の土台になります。
