# 自然性条件（Naturality Condition）

[[自然変換]] `α: F ⇒ G` が「自然」であるためには、圏 `C` の任意の射 `f :: a -> b` に対して、次の四角形が可換になる必要があります。

$$G f \circ \alpha_a = \alpha_b \circ F f$$

これは、「先に `α` で変換してから `G f` を適用する」のと「先に `F f` を適用してから `α` で変換する」のが、常に同じ結果になる、という条件です。図で描くと正方形の四辺がぴったり噛み合う形（可換図式）になります。

Haskellの多相関数がなぜ自動的にこの条件を満たすのかは興味深い事実です。型変数 `a` について「何も知らない」まま書かれた関数（`forall a. F a -> G a`）は、パラメトリック多相性の性質上、自然性条件を自動的に満たすことが知られています（これは自由定理 free theorem と呼ばれる関連する事実です）。

自然性条件は、単なる関手の組の話に留まらず、[[関手則]] と並んで「構造を保つ写像とは何か」を精密に定める、圏論の基本的な規律です。
