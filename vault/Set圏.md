# Set圏（Category of Sets）

Set圏は、対象を「集合」、射を「集合から集合への関数」とする [[圏]] の代表例です。恒等射は各集合の恒等関数、合成は通常の関数合成です。

Set圏は、私たちが日常的に慣れ親しんでいる集合と関数の世界そのものなので、圏論のさまざまな概念を初めて理解するときの「足がかり」として最適です。たとえば [[積]] はSet圏では直積集合（デカルト積）に、[[余積]] は非交和（disjoint union）に対応します。

一方でSet圏には注意点もあります。集合はその要素を自由に覗き込める（外延的に扱える）のに対し、圏論の精神では対象の中身を見ずに射の関係だけで議論します。Set圏に慣れすぎると、この「中身を見ない」抽象化のありがたみを見失いがちです。プログラマにとっては、より型システムに近い [[Hask圏]] と比較しながら学ぶと理解が深まります。
