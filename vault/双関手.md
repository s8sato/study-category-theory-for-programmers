# 双関手（Bifunctor）

双関手は、2つの引数を取る [[関手]] です。正確には、圏 `C` と `D` の直積圏 `C × D` から圏 `E` への関手として定義されます。2つの対象・2つの射を同時に写せる点が特徴です。

Haskellでの代表例はタプル型 `(,)` と `Either` です。

```haskell
bimap :: (a -> c) -> (b -> d) -> (a, b) -> (c, d)
bimap :: (a -> c) -> (b -> d) -> Either a b -> Either c d
```

`bimap` は2本の射を同時に受け取り、それぞれの成分に適用します。[[積]] や [[余積]] は、この双関手としての構造を持つことで、要素ごとの変換を自然に扱えるようになっています。

なお、自分自身の圏から自分自身への関手（1引数の関手）は自己関手（endofunctor）と呼ばれ、`Functor` 型クラスに現れる関手はほとんどがこの自己関手です。双関手は、複数の型引数を持つ型コンストラクタ（`Map k v` など）を扱う際の一般化として重要です。
