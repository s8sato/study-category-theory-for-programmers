# 直積型と直和型（Product Types and Sum Types）

多くのプログラミング言語の型システムは、[[積]] と [[余積]] の圏論的な性質をほぼそのまま反映しています。

- 直積型（product type）: 構造体・タプル・レコードなど、複数のフィールドを「同時に」すべて持つ型。Haskellでは `(a, b)` や `data Pair a b = Pair a b`。
- 直和型（sum type）: enum・タグ付きunion・代数的データ型（ADT）のうち「いずれか」を選ぶ型。Haskellでは `data Either a b = Left a | Right b`。TypeScriptの合併型 `A | B` も近い概念です。

この対応関係を数値で捉えると直感的です。要素数 `|a|` の型と `|b|` の型があるとき、直積型の要素数は `|a| × |b|`、直和型の要素数は `|a| + |b|` になります。これが「代数的データ型（Algebraic Data Type）」という名前の由来です。

型設計の実務では、「同時に必要な情報は直積で」「排他的な状態は直和で」表現するのが定石であり、これは積・余積の普遍性が持つ意味と対応しています。
