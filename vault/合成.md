# 合成（Composition）

合成は、圏の中で最も重要な操作です。`a` から `b` への [[射]] `f` と、`b` から `c` への射 `g` があるとき、それらを繋げて `a` から `c` への新しい射 `g ∘ f`（「g after f」と読む）を作れる、というのが合成のルールです。

![[composition.png|圏では、AからB、BからCへの射があれば、AからCへの合成射が必ず存在する]]

数学やHaskellの表記では、合成は右から左に読む点に注意してください。`g . f` は「まず `f` を適用し、その結果に `g` を適用する」という意味です。C言語的に書けば次のようになります。

```haskell
g . f
-- 相当するC風の実装
C g_after_f(A a) { return g(f(a)); }
```

合成が満たすべき性質が [[結合律]] です。任意の圏で、対象がいくつあっても、合成によって「AからCへの直接の道」が常に存在することが保証されます。
