# 始対象と終対象（Initial Object / Terminal Object）

[[圏]] の中で、「他のすべての対象へ、ちょうど1本ずつ射が出ている」特別な対象を始対象（initial object）と呼びます。逆に、「他のすべての対象から、ちょうど1本ずつ射が入ってくる」対象を終対象（terminal object）と呼びます。これらは互いに [[双対圏]] の関係にあります。

[[Hask圏]] では、終対象は要素を1つだけ持つ型 `()`（ユニット型）です。どんな型 `a` からも、`a -> ()` という関数はただ1つに決まるからです（すべての値を `()` に潰す関数）。一方、始対象は要素を持たない型 `Void` です。`Void -> a` という関数は、`Void` 型の値がそもそも存在しないため、空虚に（vacuously）ただ1つ定義できます。

始対象・終対象は、存在すれば [[同型射]] を除いて一意（unique up to isomorphism）であることが保証されており、これは圏論全体を貫く「普遍性」という考え方の最初の例です。
