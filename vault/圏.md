# 圏（Category）

圏とは、次の4つの部品からなる、非常にシンプルな数学的構造です。

1. [[対象]]（object）の集まり
2. 対象と対象を結ぶ [[射]]（morphism、arrow）の集まり
3. 射同士を繋げる [[合成]]（composition）という操作
4. 各対象に1つずつある [[恒等射]]（identity morphism）

これだけです。圏そのものは対象の「中身」を一切問いません。数値でもデータ型でも、あるいはただの点でも構いません。重要なのは、対象間にどんな射があり、それらがどう合成できるかという「関係の構造」だけです。

圏が満たすべき法則は2つだけで、合成の[[結合律]]と、恒等射が合成の単位元になることです。この単純さゆえに、圏論は集合論・プログラミング言語の型システム・順序関係など、驚くほど多様な対象に適用できます。

プログラマにとって身近な例は [[Hask圏]]（Haskellの型と関数を対象・射とする圏）です。型 `A`、`B` を対象、関数 `f :: A -> B` を射とみなすと、関数合成 `g . f` がまさに圏論の合成にあたります。
