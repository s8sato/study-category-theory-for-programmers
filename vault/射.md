# 射（Morphism）

射（morphism、または矢印 arrow）は、ある [[対象]] から別の対象への「関係」や「変換」を表す、圏の最も基本的な構成要素です。射 `f` が対象 `a` から `b` への射であることを `f :: a -> b` あるいは $f: a \to b$ と書きます。

重要なのは、射は必ずしも「関数」である必要はないということです。圏論における射は非常に抽象的な概念で、順序関係（`a ≤ b`）や、証明（`a ⇒ b`）なども射として扱うことができます。しかし、プログラマにとって最もイメージしやすいのは、[[Hask圏]] における射、すなわち型 `a` から型 `b` への関数 `f :: a -> b` でしょう。

射は単独では意味を持たず、[[合成]] によって繋げられ、各対象には特別な射である [[恒等射]] が存在する、という圏の構造の中で初めて役割を持ちます。
