# 同型射（Isomorphism）

2つの対象 `a`、`b` の間に射 `f :: a -> b` があり、さらに逆方向の射 `g :: b -> a` が存在して、次の等式が成り立つとき、`f`（および `g`）を同型射と呼びます。

$$g \circ f = \mathrm{id}_a \qquad f \circ g = \mathrm{id}_b$$

つまり `f` と `g` は互いに完全に打ち消し合い、[[恒等射]] に戻ります。このとき対象 `a` と `b` は「同型（isomorphic）」であるといい、圏論の視点では実質的に「同じもの」とみなされます。

プログラミングで身近な例は、タプルの入れ替え `swap :: (a, b) -> (b, a)` です。`swap` を2回適用すると元に戻るので、`swap` は自分自身を逆射に持つ同型射です。

同型射は、圏論において「等しい」という強すぎる概念の代わりによく使われる、緩やかな同一視の基準です。[[合成]] と恒等射だけを使って定義できる点も重要です。
