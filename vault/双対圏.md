# 双対圏（Opposite Category）

任意の [[圏]] `C` に対して、すべての射の向きを逆転させることで、新しい圏 `C^op`（Cの双対圏、opposite category）を作ることができます。`C` において `f :: a -> b` という射があれば、`C^op` では同じ `f` が `b -> a` という射として扱われます。

これは単なる形式的な操作に見えますが、圏論では非常に強力な道具です。ある概念を「双対化」する（矢印を逆にする）ことで、新しい概念を無料で手に入れられるからです。たとえば [[始対象と終対象]] は、互いに双対の関係にあります。「終対象の定義で矢印を全部逆にすると、始対象の定義になる」という具合です。

プログラミングとの対応で言えば、双対圏そのものを直接使う場面は多くありませんが、「入力と出力を逆にして考えるとどうなるか」という発想は、たとえばイベント駆動設計や関数のリバース・エンジニアリングを考える際のヒントになります。
