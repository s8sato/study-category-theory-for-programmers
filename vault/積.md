# 積（Product）

2つの対象 `a`、`b` の積とは、対象 `c` と、2本の射（射影）$p: c \to a$、$q: c \to b$ の組であって、[[普遍性]] ―― 同じ形の射影の組を持つ他のどんな候補 `c'` からも、`c` へ一意な射が存在する ―― を満たす、最も条件の厳しい候補のことです。

![[product-pattern.png|対象cから対象a,bへの射影p,qを持つ候補パターン]]

[[Set圏]] では、積は直積集合 `a × b`（ペアの集合）に対応します。[[Hask圏]] では、タプル型 `(a, b)` と、その2つの射影関数 `fst :: (a,b) -> a`、`snd :: (a,b) -> b` が積を実現しています。

積は [[余積]] の双対概念です。積では「候補から本命への一意な射」が必要ですが、余積では逆に「本命から候補への一意な射」が必要になります。この対称性を意識すると、両者を同時に理解しやすくなります。
