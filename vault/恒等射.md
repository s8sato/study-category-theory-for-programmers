# 恒等射（Identity Morphism）

恒等射とは、圏の中の各対象 `a` に必ず1つ存在する、「対象 `a` からそれ自身への特別な [[射]]」であり、$\mathrm{id}_a: a \to a$ と書きます。

恒等射の役割は、[[合成]] における単位元（何もしない操作）であることです。任意の射 `f :: a -> b` に対して、次の等式（恒等律）が成り立ちます。

$$f \circ \mathrm{id}_a = f = \mathrm{id}_b \circ f$$

Haskell では、恒等射は `id :: a -> a; id x = x` という関数そのものに対応します。`id` を関数合成しても、元の関数の振る舞いは変わりません。

一見当たり前に思えるかもしれませんが、恒等射の存在は圏の定義に不可欠な要件です。恒等射が保証されているおかげで、[[同型射]]（互いに打ち消し合う一対の射）という概念を定義できるようになります。
