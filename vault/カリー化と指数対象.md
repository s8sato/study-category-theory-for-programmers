# カリー化と指数対象（Currying and Exponential Object）

「2引数関数」と「1引数を受け取り関数を返す関数」が同じ情報を持つ、というのがカリー化（currying）です。Haskellでは次の同型が成り立ちます。

```haskell
curry   :: ((a, b) -> c) -> (a -> b -> c)
uncurry :: (a -> b -> c) -> ((a, b) -> c)
```

圏論では、この「`b -> c` という関数全体を表す型」を指数対象（exponential object）と呼び、$c^b$ と書きます。すると先ほどの同型は、次のように[[積]] を使って表せます。

$$\mathrm{Hom}(a \times b,\ c) \cong \mathrm{Hom}(a,\ c^b)$$

積と指数対象の両方を持つ圏を、デカルト閉圏（Cartesian Closed Category, CCC）と呼びます。[[Hask圏]] はデカルト閉圏の代表例であり、関数型プログラミングで「関数を値として自由に持ち回せる」という性質（高階関数）は、この構造に支えられています。
